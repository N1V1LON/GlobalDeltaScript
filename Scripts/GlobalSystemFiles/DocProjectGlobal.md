Контракт модуля (V26.1.2B, реализует GlobalControler)
---
- GC запускается первым и сам поднимает всё: ищет Base, читает Config, грузит GS потом GM;
- при старте НЕ открывает хаб — только лаунчер 64×64 [N]; хаб по клику, ✕ прячет хаб в [N];
- вкладки по умолчанию всегда: Player | Server | Settings (лишние слоты — после них);
- модуль — одна таблица, return + env[ИмяФайла]; имя = имя файла без .lua;
- GetTable: "Player" | "Server" | "Settings" (или функция) — вкладка в хабе;
- GetPosition: 1 (или функция) — порядок внутри вкладки;
- Name, Desc — подпись карточки в хабе;
- Open(config) — по клику карточки UI открывается **внутри хаба** (без отдельного окна); ← возвращает к карточкам;
- GC временно выставляет GC._moduleHost — WindowBase parent'ит туда и ставит _embedded (без ScreenGui/ClaimPosition);
- **embed: у WindowBase НЕ создаётся своя шапка** (title/min/✕) — только одна шапка хаба (← / название / badge / ✕); контент = весь ModuleHost;
- окна плавающие (если Open зовут вне хаба) берут позицию через GC:ClaimPosition(w,h), Release через GC:ReleaseWindow;
- иконка: Config.icons[ИмяФайла] → getcustomasset;
- повторный запуск GC: если уже Running — выходит и ничего не пересоздаёт.
